# Статьи и исследования

Добро пожаловать! Здесь собраны статьи, заметки и исследования, к которым хочется возвращаться.

Выберите статью в навигации слева. На телефоне откройте меню кнопкой в верхней панели. Новые публикации автоматически появляются в меню, а поиск помогает найти нужную мысль среди всех материалов.

Для знакомства с оформлением откройте [демонстрационную статью](articles/example.md). Внутри каждой статьи есть содержание со ссылками на разделы; ссылкой у заголовка можно поделиться, чтобы открыть нужное место сразу.
